## Console hardening

- **Firebase iOS API key:** Google Cloud Console → APIs & Services → Credentials → the Firebase iOS API key → Application restrictions: *iOS apps* with this app's bundle ID; API restrictions: *Restrict key* to **Identity Toolkit API** (plus Token Service API if the console lists it as required for Auth). Re-test Google and Apple sign-in afterwards.
- **Firebase App Check:** Firebase console → App Check → register the iOS app with the **App Attest** provider, then monitor metrics before enforcing for Authentication. Enforcing before the client sends App Check tokens will lock out sign-in, so add the SDK/client token first.
- **Account deletion and RevenueCat:** in-app deletion removes the Firebase account but only logs out of RevenueCat; it does not delete the RevenueCat customer. Delete (or anonymize) the RevenueCat customer for that UID through the dashboard's customer deletion / privacy-request workflow, or a protected server using the secret API. Never ship the secret API key in the client.
